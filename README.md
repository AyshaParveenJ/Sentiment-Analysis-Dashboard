#  Sentiment Analysis Dashboard

A modern, responsive Single Page Application (SPA) built with **React** for the frontend and styled efficiently using **Tailwind CSS**.

This dashboard is designed to process and visualize sentiment data, offering a clean, user-friendly interface to interpret complex sentiment analysis results.

##  Key Features

* **Data Visualization:** 
Displays key metrics like overall sentiment score, and distribution charts for positive, negative, and neutral sentiments. 
* **Tailwind CSS Styling:**
 Utilizes a custom Tailwind CSS configuration for a utility-first approach and highly responsive design.
* **Component-Based Architecture:** 
Built with reusable React components for maintainability and scalability.
* **Optimized Build:**
 Uses Create React App's standard build process for production-ready, highly optimized static assets.
